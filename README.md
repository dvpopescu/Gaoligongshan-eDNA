# Statistical Analysis Code for the 2023 Gaoligongshan eDNA Study

This repository contains all the statistical analysis code for the research paper "High quality, granular, timely, trustworthy, and efficient vertebrate species distribution data across a 30,000 km2 protected area complex" (Yinqiu Ji, Alex Diana, Xueyou Li, et al.).

This repository aims to provide a transparent and reproducible analysis workflow for processing environmental DNA (eDNA) data collected in the Gaoligongshan region to assess vertebrate species distribution.

## Repository Structure

The repository is organized into three main directories: `data` for raw data, `src` for analysis scripts, and `outputs` for results.

### `data/`

This directory contains all the input data required for the analysis.

* `glgs/`: Contains GIS vector data (shapefiles) used for mapping.
    * **Note:** The file `forest_1km.tif` is not included in this directory as it is too large to be uploaded to GitHub. This file is used as a background layer for generating Figure 3, Supp. Figure 1, Supp. Figure 2, Supp. Figure 6, and Supp. Figure 7. To reproduce the relevant code, you can either comment out the lines that use this forest layer or contact the authors to request the file.
* `23GLG_covs_info_20240927.txt`: Environmental covariate data for sample sites, including `Human_modification_1km`, `Percent_of_forest_cover_1km`, `Patch_density_1km`, `Edge_density_1km`, and `Reservoir_downstream`.
* `23GLG_zones_info_20240903.txt`: Regional division covariate data for sample sites (`Regional_Division`).
* `GLGS_climate.csv`: Climate factor covariate data for sample sites, including `annual_precipitation` and `mean_temperature`.
* `OTUtable_12S_toSP_GLG23_20240528.txt`: The OTU (Operational Taxonomic Unit) table generated from bioinformatics analysis. It also includes detailed sample metadata such as sampling date, latitude/longitude, elevation, river system information, river parameters (width, depth, velocity), water quality indicators (temperature, dissolved oxygen, conductivity, pH), precipitation data, river distance from protected area boundaries, and water volume filtered.
* `SP_withBODYSIZE.txt`: Detailed information for species detected in this study, including corresponding OTU ID, class, species Latin name, conservation status in IUCN and China Red List, local status (wild/domesticated/invasive), and adult body mass for mammal species (source: Pantheria).
* `gaoligongshan_AmphRept_data_20241014.rda`: Input data for `occPlus` modeling of amphibians and reptiles, generated by `6_occPlus_cleaning_20241014.R`.
* `gaoligongshan_Ave_data_20240912.rda`: Input data for `occPlus` modeling of birds, generated by `6_occPlus_cleaning_20241014.R`.
* `gaoligongshan_FISH_data_20240912.rda`: Input data for `occPlus` modeling of fish, generated by `6_occPlus_cleaning_20241014.R`.
* `gaoligongshan_Mammal_data_20240912.rda`: Input data for `occPlus` modeling of mammals, generated by `6_occPlus_cleaning_20241014.R`.
* `gaoligongshan_bullfrog_data_20250127.rda`: Input data for `occPlus` modeling of the American bullfrog, generated by `6_occPlus_cleaning_20250127forbullfrog.R`.

### `src/`

This directory contains all R scripts and Stan code for data processing, statistical modeling, and visualization.

* **Data Cleaning Scripts:**
    * `6_occPlus_cleaning_20241014.R`: Reads and cleans eDNA and environmental data, filters species, constructs OTU matrices for amphibians/reptiles, mammals, birds, and fish, and generates `.rda` data files for `occPlus` occupancy modeling.
    * `6_occPlus_cleaning_20250127forbullfrog.R`: Same function as above, but specifically prepares the input data for the American bullfrog (single species).

* **MSOM Modeling Scripts:**
    * `3_msom_AmphRept_20241018.R`: Performs multi-species occupancy modeling (MSOM) for amphibians and reptiles.
    * `3_msom_Ave_20241018.R`: Performs MSOM for birds.
    * `3_msom_FISH_20241018.R`: Performs MSOM for fish.
    * `3_msom_Mammal_20241018.R`: Performs MSOM for mammals.
    * `3_spocc_bullfrog_20250125.R`: Performs single-species occupancy modeling for the American bullfrog using the `spOcc` function from the `spOccupancy` package.

* **occPlus Modeling Scripts:**
    * `4_occPlus_AmphRept_20241018.R`: Performs `occPlus` modeling for amphibians and reptiles.
    * `4_occPlus_Ave_20241018.R`: Performs `occPlus` modeling for birds.
    * `4_occPlus_FISH_20241018.R`: Performs `occPlus` modeling for fish.
    * `4_occPlus_Mammal_20241018.R`: Performs `occPlus` modeling for mammals.
    * `4_occPlus_bullfrog_20250127.R`: Performs `occPlus` modeling for the American bullfrog (using a version adapted for single-species analysis).
    * `5_occPlus_function_20241008.R`: Source code for helper functions required for multi-species `occPlus` models.
    * `5_occPlus_function_singlespecies.R`: Source code for helper functions required for single-species `occPlus` models.
    * `code_pcr_ccord2.stan` / `.rds`: The Stan model definition file for the multi-species `occPlus` model and its companion `.rds` file.
    * `code_pcr_ccord_singlespecies.stan` / `.rds`: The Stan model definition file for the single-species `occPlus` model and its companion `.rds` file.

* **Results Visualization Scripts:**
    * `7_mapping_occupancy_20241018.R`: Performs spatial visualization (mapping) of raw eDNA data and occupancy model outputs.
    * `9_combine_results_20241018.R`: This script reads the output from MSOM and occPlus models, then summarizes, compares, and visualizes species occupancy, detection rates, and the effects of environmental covariates to generate most of the statistical figures in the paper.

### `outputs/`

This directory is for storing files generated by the scripts in `src/`, including figures and intermediate results.

## Analysis Workflow

To fully reproduce the analysis in this study, please execute the scripts in the following order:

1.  **MSOM Modeling:**
    * Run the `src/3_msom_*.R` series of scripts to perform MSOM modeling for each taxonomic group (amphibians/reptiles, birds, fish, mammals).

2.  **Prepare `occPlus` Input Data:**
    * Run `src/6_occPlus_cleaning_20241014.R` to generate the `.rda` input files for the four main taxonomic groups. These files will be saved in the `data/` directory.
    * Run `src/6_occPlus_cleaning_20250127forbullfrog.R` to generate the separate `.rda` input file for the American bullfrog.

3.  **`occPlus` Modeling:**
    * Run the `src/4_occPlus_*.R` series of scripts to perform `occPlus` modeling for each taxonomic group and the bullfrog. These scripts depend on the `.rda` files generated in Step 2.

4.  **Result Visualization and Integration:**
    * Run the `src/7_mapping_occupancy_20241018.R` and `src/9_combine_results_20241018.R` scripts. These scripts read the raw data and model outputs to generate all the figures presented in the paper.

## Setup and Dependencies

### Software Requirements
* R (version 4.4.2 or later recommended)
* RStudio (recommended)
* Stan (usually handled automatically by the `rstan` R package)
